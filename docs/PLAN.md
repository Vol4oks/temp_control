## Этап 2.1. Калибровка датчика 🔧

> Подход подтверждён (Plan-ID: CAL1): двухточечная калибровка,
> через `config.toml` и браузер (Этап 4).

- [x] Секция `[calibration]` в `config.toml` — 2 пары точек × T/H, опциональна (по умолчанию идентичность)
- [x] Модуль `src/calibration.rs`: точки, валидация (конечность, X не совпадают), линейный пересчёт
- [x] `Reading` несёт сырое И откалиброванное значение (нужно для снятия точек)
- [x] `Arc<Mutex<Calibration>>` — общее состояние для runtime-изменения из веб-задачи
- [ ] Проверка на железе (по умолчанию идентичность — raw == calibrated)

Браузерная часть (в Этапе 4):

- [ ] `GET /api/calibration` — текущие точки и источник (config | nvs)
- [ ] `POST /api/calibration` — задать точки (валидация → применение → запись в NVS)
- [ ] `POST /api/calibration/reset` — сброс к значениям из `config.toml`
- [ ] Веб-UI: **сетка значений с перетаскиваемыми точками** — X «показал датчик», Y «реально», две точки на канал (T: 0…50 °C, H: 0…100 %), линия идентичности для справки; при отпускании точки — POST
- [ ] NVS: калибровка переживает перезагрузку, приоритет над `config.toml`

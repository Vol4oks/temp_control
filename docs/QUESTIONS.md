## ОВ-1. Распиновка — ✅ решён

Подтверждено пользователем 2026-09-23:

| Устройство | Пин | Статус |
|------------|-----|--------|
| DHT11 DATA | GPIO4 | ✅ |
| SSD1306 SDA | GPIO6 | ✅ |
| SSD1306 SCL | GPIO7 | ✅ |

Значения вынесены в `config.toml` (`[pins]`).
Примечание: GPIO4–7 на ESP32-C6 — пины внешнего JTAG, отладка через внешний
JTAG будет недоступна; прошивка через USB при этом работает.

## ОВ-2. Wi-Fi конфигурация — ⏳ открыт

Предложение: env-переменные `WIFI_SSID` / `WIFI_PASS` при прошивке:

```fish
WIFI_SSID="MyNet" WIFI_PASS="..." cargo espflash flash --monitor
```

Альтернатива: хардкод в `config.toml` (не рекомендуется — секрет в git)
или NVS (сложнее первый запуск).

## ОВ-6. Калибровка DHT11 — ✅ подход решён

Решение (2026-09-23, Plan-ID: CAL1): двухточечная калибровка
`real = k·measured + b` через две пары «показал датчик → реально есть»,
отдельно для T и H.

- Конфиг: секция `[calibration]` в `config.toml` — реализовано (Этап 2.1)
- Браузер: интерактивная сетка с перетаскиваемыми точками + API + NVS — Этап 4
- Приоритет: NVS (браузер) > config.toml

Замечание по снятию точек: опорные точки брать в заметно разных условиях
(близкие measured дают нестабильный наклон). Сравнивать с эталонным
термометром; сырые значения видны в логе и будут в API (`raw_*`).
